# Gabriel Bustos | Portafolio

Portafolio profesional de Gabriel Bustos, desarrollador de sitios web, aplicaciones y soluciones de datos. El sitio reúne proyectos, servicios, formación y vías de contacto.

## Sitio publicado

**[gabrielbustos-ai.github.io](https://gabrielbustos-ai.github.io/)**

## Contenido

- Presentación y servicios de desarrollo web, automatización, análisis de datos y mapas.
- Proyectos destacados con enlaces a demostraciones y repositorios.
- Certificados y cursos en un carrusel interactivo.
- Formulario de contacto y accesos a WhatsApp, correo, LinkedIn y GitHub.
- Diseño adaptable a dispositivos móviles, tema claro/oscuro y fondo gráfico de ondas.

## Tecnologías

- HTML
- CSS
- JavaScript
- Web3Forms para el envío del formulario de contacto
- GitHub Pages para el alojamiento

## Estructura del proyecto

```text
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    ├── certificados/
    └── imágenes y logos
```

## Ejecutar localmente

El sitio es estático y no requiere instalación de dependencias ni un proceso de compilación. Cloná el repositorio y abrí `index.html` en el navegador. Para una experiencia más cercana a la publicación, podés servir la carpeta con una extensión como **Live Server** en Visual Studio Code.

## Publicación

El sitio se publica con GitHub Pages desde la rama principal del repositorio, usando la carpeta raíz como fuente. Después de publicar cambios, GitHub Pages actualiza el sitio en:

https://gabrielbustos-ai.github.io/
